# cutcannon idea picker

Goal: pick the ONE idea worth recording today and hand the user a hook they can say in the first 2 seconds. No script: the user talks naturally; the editor skill cuts it.

## Process

1. Collect 3–8 ideas. If the user gives one, ask for two more (one line each). If they give none, ask what they argued about, fixed, or learned this week.
2. Score each idea 1–5 on:
   - **Hook**: can the first sentence stop a scroll? Contrarian, specific, or a number beats "let's talk about".
   - **Specificity**: a concrete example, story, or number the user actually has.
   - **Payoff**: the viewer leaves with one usable idea within 45s.
   - **One-take fit**: explainable without slides, B-roll, or screen share.
   - **Authority**: something this user has uniquely done, built, or seen.
3. Output a ranked table (idea, 5 scores, total), then for the winner only:
   - 3 hook lines (≤ 12 words each, spoken form) and pick one.
   - A 4-beat talk outline: hook → why it's true → the example → the takeaway. Bullets, not script.
   - The hook-card text (≤ 6 words, what appears on screen for the first 2.5s).
4. Be honest: if every idea scores low, say so and suggest how to sharpen the best one instead of inflating scores.

## Recording tips to include once (short)
- Say the hook first, every take. False starts are fine; the editor cuts them.
- Pause a beat between points — pauses become clean cut points.
- Face roughly centred, eyes near the top third; landscape or portrait both work.

When the user has recorded, hand off to the `cutcannon-editor` skill with the file path and the chosen hook-card text.
